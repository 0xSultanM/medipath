How to use

  • 1 Resize to 360 / 768 / 1440 px: tables stack into cards <640, navbars/sidebars become slide-over drawers <768 (<992 for the role sidebar), doctor grids run 1/2/3 columns.
  • 2 Dashed Data view blocks carry a pure-CSS Success · Skeleton · Empty · Error+Retry switch (:has() — works with JS disabled).
  • 3 Money is always {{CURRENCY}} 1,200.00 — never a literal dollar sign; DB-driven labels are marked data-src="db:…".
  • 4 Emergency red (#B91C1C) appears only in emergency UI regions: emergency strip/page, chatbot red-flag intercept, symptom escalation modal, red-flag rule badges, red-flag log events. Routine destructive/error UI uses danger (#DC2626).
